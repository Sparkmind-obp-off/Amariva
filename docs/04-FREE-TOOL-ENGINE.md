# AMARIVA — FREE TOOL ENGINE

## Mission

Free tools are AMARIVA's primary demand-capture mechanism.

A successful free tool is not a gimmick. It performs a real job immediately.

## Free Tool Flywheel

```
Search / Social
      ↓
Free Tool
      ↓
Useful Result
      ↓
Explanation
      ↓
Related Content
      ↓
Email / Save / Share
      ↓
Relevant Paid Offer
```

## Tool Selection Framework

Prioritize tools with:

1. clear user intent,
2. simple input,
3. immediate output,
4. easy explanation,
5. repeat or referral potential,
6. logical paid expansion.

## Tool Families

### Calculate
Margins, pricing, break-even, capacity, fees.

### Estimate
Time, cost, quantity, workload, revenue.

### Diagnose
Business health, workflow gaps, readiness, operational score.

### Plan
Schedules, checklists, targets, simple plans.

### Generate
Templates, copy, labels, task lists, structured outputs.

### Compare
Options, scenarios, trade-offs.

## Tool Page Structure

1. H1 matching the user problem.
2. One-sentence promise.
3. Inputs.
4. Result.
5. Explanation.
6. Recommended next step.
7. Related content.
8. Relevant paid offer.
9. Trust/privacy note.

## Conversion Design

Do not gate the basic result unnecessarily.

A better pattern:

**free result → deeper value → optional save/export/email → related paid solution**

The visitor should experience value before being asked to buy.

## Tool Portfolio Rule

Do not launch 30 tools at once.

Launch a small portfolio around one demand cluster.

Example:

**Pricing cluster**
- pricing calculator,
- margin calculator,
- break-even calculator,
- price comparison guide,
- pricing template pack.

The cluster creates internal linking, repeat use, and monetization logic.

## Tool Success Metrics

Primary:

- tool starts,
- tool completion,
- result rate,
- repeat usage,
- qualified CTA clicks,
- lead conversion,
- paid conversion.

Secondary:

- shares,
- backlinks,
- rankings,
- return visits.

Traffic alone does not define success.
