# AMARIVA — CONTENT & SEO ENGINE

## Objective

Content should capture demand before, during, and after tool usage.

AMARIVA is not a media company. Content exists to:

**answer intent → demonstrate expertise → route traffic → strengthen tools/products → convert.**

## Content Pillars

### 1. Problem Content
“How do I…?”

### 2. Decision Content
“Which option should I choose?”

### 3. Tool-Adjacent Content
“How to calculate/estimate/check…”

### 4. Product Education
“How to use…”

### 5. Comparison Content
“A vs B”

### 6. Operational Playbooks
Step-by-step execution.

### 7. Evidence / Case Content
What happened and what was learned.

## Search Strategy

Build topic clusters rather than isolated articles.

```
Core topic
 ├─ free tool
 ├─ guide
 ├─ FAQ
 ├─ comparison
 ├─ example
 ├─ template
 └─ paid product
```

Every cluster should have a clear user journey.

## Content Quality Rules

Every page should add at least one of:

- original calculation,
- original framework,
- actionable example,
- useful template,
- observed data,
- real workflow,
- tool,
- meaningful comparison.

Do not mass-produce shallow AI content.

## SEO Architecture

Prefer:

- clean URLs,
- descriptive titles,
- useful H1s,
- internal links,
- structured data where appropriate,
- fast pages,
- accessible interfaces,
- canonical URLs,
- indexable tool pages where useful,
- strong page-level intent.

## Content Funnel

**Discovery**
→ problem article

**Evaluation**
→ guide/comparison

**Activation**
→ free tool

**Conversion**
→ product page

**Retention**
→ email/update/use case

## Editorial Cadence

A sustainable starting cadence:

- 1–2 meaningful search-driven pieces/week,
- 2–4 distribution adaptations/week,
- continuous improvement of existing pages,
- new tools only when supported by demand.

Publishing more is not inherently better.

## Repurposing System

One strong research item can become:

**article → tool → short post → carousel → video script → FAQ → email → product improvement**

This is the preferred content model because it compounds one research effort.
