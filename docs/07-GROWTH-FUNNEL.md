# AMARIVA — GROWTH FUNNEL

## Canonical Funnel

```
DEMAND
  ↓
DISCOVERY
  ↓
FREE VALUE
  ↓
USAGE
  ↓
LEAD
  ↓
OPPORTUNITY
  ↓
OFFER
  ↓
TRANSACTION
  ↓
DELIVERY
  ↓
RETENTION
  ↓
EXPANSION
  ↓
LEARNING
```

## Funnel Definitions

### Discovery
A user sees or searches for a relevant problem.

Metric:
**qualified visits**

### Free Value
User reaches a useful asset.

Metric:
**tool/content activation**

### Usage
User actually completes the job.

Metric:
**completion / output generated**

### Lead
User voluntarily enters an owned channel.

Metric:
**qualified lead rate**

### Opportunity
User demonstrates buying intent.

Metric:
**offer view, pricing view, checkout start, demo request, or equivalent**

### Transaction
Payment or committed purchase.

Metric:
**paid conversion rate**

### Delivery
Buyer receives the promised value.

Metric:
**time-to-value / fulfillment success**

### Retention
Buyer returns or continues usage.

Metric:
**repeat purchase / active subscription / repeat tool usage**

### Expansion
Buyer adopts another relevant offer.

Metric:
**cross-sell / upsell rate**

## North-Star Logic

Do not use followers or raw pageviews as the primary north star.

Better leading metrics:

**Qualified Intent Captured**

and ultimately:

**Contribution Margin from repeatable demand sources**

## Funnel Diagnosis

If traffic is high but tool starts are low:
**message / relevance problem.**

If tool usage is high but leads are low:
**next-step / trust problem.**

If leads are high but purchases are low:
**offer / pricing / proof problem.**

If purchases are high but retention is low:
**delivery / product value problem.**

This keeps optimization causal instead of random.
