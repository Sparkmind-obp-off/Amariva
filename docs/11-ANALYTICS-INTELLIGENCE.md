# AMARIVA — ANALYTICS & INTELLIGENCE

## Objective

Turn every meaningful customer interaction into a decision signal.

## Event Model

Core events:

- page_view
- tool_start
- tool_complete
- result_view
- email_opt_in
- product_view
- checkout_start
- purchase
- delivery_complete
- activation
- repeat_use
- repeat_purchase
- upgrade
- cancellation
- referral

## Dimensions

Track by:

- source,
- landing page,
- tool,
- topic,
- offer,
- product,
- device,
- geography when appropriate,
- first-time vs returning.

## Metrics

### Acquisition
- qualified visits,
- organic sessions,
- distribution clicks,
- tool starts.

### Activation
- completion rate,
- result quality signals,
- return usage.

### Conversion
- lead rate,
- checkout start rate,
- purchase rate,
- revenue per visitor.

### Retention
- repeat use,
- repeat purchase,
- subscription retention.

### Economics
- contribution margin,
- acquisition cost,
- support cost,
- refund rate.

## Demand Intelligence

The most valuable intelligence questions are:

1. What problems are people repeatedly trying to solve?
2. Which free assets attract high-intent users?
3. Which free assets create qualified commercial intent?
4. Which offers convert?
5. Which customers return?
6. Which adjacent problems appear after purchase?

## Opportunity Scoring

A simple internal score:

**Demand × Pain × Intent × Monetization × Distribution × Strategic Fit**

Use a consistent scale and record assumptions.

## Experiment Log

Every experiment records:

- hypothesis,
- change,
- expected result,
- metric,
- start date,
- stop condition,
- actual result,
- lesson,
- next action.

## Decision Loop

```
DATA
↓
INSIGHT
↓
HYPOTHESIS
↓
EXPERIMENT
↓
RESULT
↓

```

This is the intelligence layer AMARIVA should compound over time.
